# HTML Exercise - Blog App

The purpose of this exercise is to practice using HTML to build a simple blogging website.

## Instructions

### 1. Setup GitHub Repository

Create a public GitHub repository named:

```bash
blog-app
```

---

### 2. Create Project Locally

Create a project on your local machine and name it:

```bash
blog-app
```

---

## Requirements

### 1. Create `index.html`

- Add the basic HTML structure
- Set the document title to:

```txt
Trizah’s Blog
```

- Create a navigation bar with:
  - Your name as the logo
  - Navigation links for:
    - About
    - Blog
    - Login
    - Create
    - LinkedIn (logo/icon)

- Download the LinkedIn SVG icon from:

```txt
https://www.svgrepo.com/svg/157006/linkedin
```

- Use the SVG inside an `<img>` tag

#### Navigation Links

| Link      | Destination        |
| ---------- | ------------------ |
| About      | `/about.html`      |
| Blog       | `/`                |
| Login      | `/login.html`      |
| Create     | `/create.html`     |
| LinkedIn   | Your LinkedIn URL  |

- LinkedIn should open in a new tab

#### Footer

Add a footer containing:

- Copyright message
- Current year
- Text:

```txt
Built with ❤️ by Trizah.
```

#### Blog List

Display a list of **5 blog posts**.

Each blog should include:

- Blog title
- Description (maximum 100 words)
- Published date
- Author

---

### 2. Create `about.html`

The page should contain:

- Greetings
- A brief introduction about yourself
- Your hobbies

#### Contact Form

Create a form titled:

```txt
Get in touch
```

The form should contain:

- Name field
- Email field
- Message field
- Submit button

---

### 3. Create `login.html`

Create a simple login form with:

- Email field
- Password field
- Submit button with text:

```txt
Login
```

---

### 4. Create `create.html`

Create a form with the heading:

```txt
Create a Blog
```

The form should contain:

- Blog title field
- Blog body field
- Multiple select field for tags

#### Tags Options

- Science
- IT
- Biotech
- Economy
- Sports

> Make sure users can select more than one option.

Add a submit button with text:

```txt
Create
```

---

### 5. Footer

Each page should contain the same footer.

---

### 6. Navigation Bar

The navigation bar should appear on all pages and all links should work correctly.
